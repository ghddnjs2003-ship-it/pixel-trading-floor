# PIXEL TRADING FLOOR · 데모 버전

13명의 픽셀 트레이더가 사무실에서 일하는 모습과, 실시간 바이비트 시세 기반의 모의 트레이딩 화면을 담은 정적 웹 데모입니다.

## 바로 열기

- 웹: https://ghddnjs2003-ship-it.github.io/pixel-trading-floor/
- 휴대폰은 세로 화면(9:16) 레이아웃으로 자동 전환됩니다. 강제로 켜려면 `?vertical=1`, 끄려면 `?vertical=0`.

## 구성

- `index.html` — 사무실(13인 데스크) 화면과 진입점
- `app.js`, `hq.js`, `stage.js`, `qr.js` — 사무실 연출·UI
- `style.css`, `hq.css` — 사무실 화면 스타일, `lite/lite.css` — 모바일·데모 레이어
- `lite/` — 서버 없이 도는 데모 엔진(모의 매매·차트·지표, `shim.js`가 `/api/*`를 가로챕니다)
- `lite/screener.js`, `lite/screener.css` — `[스크리너]` 탭(바이비트 무기한·현물 USDT 종목, 실시간 웹소켓 시세)
- `lite/global.js`, `lite/global.css` — 글로벌 시황: `[사무실]`·`[트레이딩]` 탭의 상단 슬림 전광판(36px)과 `[스크리너]` 탭의 7칸 요약 카드(좁은 화면은 한 줄 요약 칩 + 접기/펼치기)
- `lite/pro.js`, `lite/pro.css` — `[트레이딩]` 실전 기능 3종: 선물 수급 3대장(펀딩비·미결제약정·롱숏 비율), 손절 기준 수량 계산기, 모의 매매 성적표
- `lite/paperfeed.js` — 성적표 모달의 **🤖 30분봉 Gemini AI 모의매매 현황**. `backend/paper_loop.py`가 30분마다 남기는 `data/paper_state.json`·`data/paper_log.jsonl`을 읽어 모의 자본·마지막 스캔(관망/진입/청산)·승률·PF·킬스위치·판단 로그를 보여 줍니다(키는 서버 `.env`에만 있어 화면에 나오지 않습니다)
- `data/paper_state.json`, `data/paper_log.jsonl`, `data/paper_killswitch.json` — 모의매매 루프의 상태·판단 기록(모의 계좌 숫자만). 위 화면이 읽을 수 있게 저장소에 함께 커밋하고, 30분 루프가 갱신해 푸시합니다
- `lite/whale.js`, `lite/whale.css` — `[고래·일정]` 탭: 실시간 TRC20 고래 입출금(50만 달러 이상)과 이번 주 미국 주요 경제 일정
- `data/calendar.json` — 이번 주 미국 주요 지표(High·Medium)를 한국 시간·한국어로 담은 일정표. `scripts/update-global.py --calendar`가 만들고 `.github/workflows/update-global.yml`이 함께 갱신합니다
- `data/global.json` — 미 선물·달러 인덱스·원/달러 스냅숏(24시간 스파크 포함). `scripts/update-global.py`가 만들고 `.github/workflows/update-global.yml`이 10분마다 갱신합니다
- `backend/` — 선택 사항인 Python 서버. 13인 LLM 분석(무료 API·로컬 Ollama 공용 어댑터), **더블 S+MDS v7 룰 엔진**, **과거 캔들 백테스트**, **AI 맥락 필터**(Gemini가 M1 후보를 PASS/REJECT), **실시간 모의매매 루프**(`/api/paper`), **킬스위치**가 있습니다. GitHub Pages에는 쓰이지 않습니다 — `backend/README.md` 참고.

## ✨ 픽셀 오피스 ◆ 정밀 분석 = Gemini AI 13인 (2026-11-20)

- `◆ 정밀 분석`을 누르면 브라우저 안 규칙 대신 **진짜 Gemini AI 13인 팀**(애널리스트 4 · 리서치룸 BULL/BEAR 2라운드 · ACE 결재 · 리스크 위원회 3 · PM 승인)이 회의하고 판정합니다. 말풍선·Agent Console·최종 판정이 모두 Gemini가 쓴 한국어입니다.
- 키는 **Cloudflare Worker Secret `GEMINI_API_KEY`** 에만 있습니다 — 브라우저 JS·저장소에 키가 없습니다. `lite/gemini.js`가 `https://pixel-global.jooyon124.workers.dev/ai-analyze`(POST)만 호출합니다. Worker·배포 방법은 `worker/README.md`.
- **숫자는 AI가 아니라 규칙이 정합니다.** Gemini는 방향·확신도·근거를 말하고, 진입·손절·목표·청산가는 `lite/brain.js`가 다시 계산합니다. 그래서 손절이 청산가 안쪽인지 보는 리스크 게이트와 화면 스키마가 그대로 유지됩니다(게이트 강등 시 HOLD).
- 판정 패널 머리에 **`✨ Gemini AI · 3.5 flash lite`** / **`체험 규칙 B안`** 배지로 이번 판정의 출처를 표시합니다.
- 응답 실패·무료 한도(429)·연결 오류면 **체험 규칙(B안)으로 자동 폴백**해 화면이 멈추지 않습니다. 프론트는 15초 쿨다운, 시연(`?kiosk=1`)·`?ai=0`에서는 AI를 부르지 않습니다.
- 모델 폴백 `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite`(실사이트에서 3.1로 자동 전환되는 것까지 확인). 응답 2~4초.

## 글로벌 시황

- `[사무실]`·`[트레이딩]` 탭 — 화면 맨 위에 한 줄 전광판: NQ 선물 · ES 선물 · DXY · 원/달러 · 김프 · BTC 도미넌스 · 공포탐욕
- `[스크리너]` 탭 — 필터 줄 아래 7칸 요약 카드: 미 선물은 24시간 스파크라인, 도미넌스는 BTC/ETH 비중 막대, 공포탐욕은 게이지. 좁은 화면(≤820px)에서는 카드가 기본으로 접혀 한 줄 요약 칩만 보이고, `카드 펼치기` 버튼으로 전체 카드를 폅니다(선택은 브라우저에 기억).
- 값은 서버 없이 브라우저가 직접 받습니다: 업비트 웹소켓 실시간 체결가 + 코인베이스 달러(60초)로 김프, CoinGecko `/api/v3/global`(3분, 429면 Coinlore로 자동 전환), alternative.me 공포탐욕(10분).
- 업비트 REST·웹소켓은 사이트 주소(Origin)당 호출 수가 작아, 붙지 못하면 빗썸 공개 시세로 물러나 김프를 계속 계산합니다(카드에 출처를 그대로 표시).
- 미 선물(NQ·ES)·달러 인덱스·원/달러는 야후 파이낸스에 CORS 헤더가 없어 브라우저가 직접 못 받습니다. 그래서 Cloudflare Worker(`https://pixel-global.jooyon124.workers.dev/global.json`, 45초 캐시·CORS 허용)가 대신 받아 내주고, 페이지는 1분마다 그 값을 다시 받습니다. 워커가 막히면 GitHub Actions가 커밋해 둔 `data/global.json` 스냅숏으로 물러납니다(그때는 스냅숏의 `updatedAt`이 곧 값의 나이).
- 값이 30분보다 낡으면 SYNC 표시가 노랗게 바뀝니다.

## 실전 기능 3종 (`[트레이딩]`, `lite/pro.js`)

- **선물 수급 3대장** — 차트 위 서브바. 펀딩비와 다음 정산 카운트다운(1초 틱), 미결제약정 규모·24시간 변동률·스파크라인, 롱/숏 계정 비율 게이지. 바이비트 V5 공개 API(`/v5/market/tickers`·`/open-interest`·`/account-ratio`)에서 키 없이 받아 30초마다 갱신하고, 종목을 바꾸면 즉시 다시 받습니다. 한 엔드포인트가 실패해도 나머지는 그대로 보이고 상태 줄에 `OI 지연`처럼 표시합니다.
- **손절 기준 수량 계산기** — 주문 패널의 `[손실 한도 | 증거금 직접]` 토글. 최대 손실 금액(모의 잔고 0.5%·1%·2% 칩)과 손절가만 넣으면 진입 수량·필요 증거금·손익비를 계산해 주문 증거금에 자동으로 넣습니다. 손실 한도 모드에서는 증거금 직접 입력칸을 접습니다.
- **모의 매매 성적표** — 마켓바의 `📊 매매 성적`. 실제 모의 계좌 체결 기록으로 누적 수익·승률·평균 손익비·MDD·수익 곡선·최근 복기 표를 집계합니다(기간 오늘/7일/30일/전체). 거래가 없으면 빈 상태 안내만 보여 줍니다.
- **🤖 30분봉 Gemini AI 모의매매 현황** — 같은 모달 안, 모의 계좌 카드 아래. 백엔드 `paper_loop`의 최신 스냅숏(모의 자본 10,000 USDT·마지막 스캔·체결·승률·PF·킬스위치)과 봉별 판단 로그(관망/진입/청산 + Gemini PASS/REJECT)를 읽기 전용으로 보여 줍니다. 모달을 열 때 새로 받고, 열어 둔 동안 60초마다 갱신합니다.

## 체험판 판정 규칙 (2026-11-20 B안 확정, `lite/brain.js`)

- **익절 +20% / 손절 −30%(손익비 0.67)** — 증거금 기준(100배에서 가격 +0.2%/−0.3%). 손익분기 승률 **60%**이고, 손절이 청산가(−0.5%)보다 앞에 있습니다. (기존 +15%/−30%는 손익분기 67%라 61% 승률이면 손실 구간이었습니다.)
- **관망(HOLD)은 두 경우만** — 1시간 추세가 불명확(EMA50 ±0.1% 안)하거나 RSI 추격(롱 75 이상·숏 25 이하) 구간이면 진입하지 않고 관망합니다. 트리거(6시간 박스 돌파·볼린저 되돌림)는 **있으면 확신도 가점, 없어도 추세가 서 있으면 진입**합니다(`RULES.requireTrigger: false`). 화면에는 `HOLD`와 함께 왜 거뒀는지·다음에 볼 조건이 표시됩니다.
- 실측(OKX BTC 5분봉 3,785봉·약 15일, 100배): 옛 15/30(전부 진입) 승률 61.4%·손익분기 67%로 마이너스, A안(20/20·트리거까지 요구) 47.6%로 마이너스, **B안(20/30·트리거 없는 추세 진입 허용) 승률 57.5%·건당 기대 +0.94%p**(2시간 보유 기준 62.7%·+2.05%p). 표본이 짧아 확정된 엣지가 아니라 참고값입니다.

## 고래·일정 (`lite/whale.js`)

- **실시간 고래 입출금** — TRC20 USDT 이체 중 **50만 달러(≈7억원) 이상**만 모아 30초마다 새로 훑습니다.
  - 이체 목록은 TronGrid 공개 API(`/v1/contracts/{USDT}/events`, 한 번에 200건)에서 받습니다. 키 없이 1초에 1회까지 허용되어 장 사이를 1.1초씩 띄웁니다.
  - 거래소 이름표(`Binance-Hot 16`, `Bybit`, `Bitfinex` …)는 TronScan 공개 API에서 90초에 한 장씩 받아 **주소 → 이름** 표를 쌓아 두고 모든 줄에 함께 씁니다(TronScan은 익명 호출을 자주 막아 429면 4분 쉽니다).
  - 한 장이 1~3초 분량이라 흐름 전체를 볼 수는 없습니다. 그래서 훑은 것 중 50만 달러 이상만 최근 3시간·26건까지 쌓아 두고, 화면의 `최근 15분 N건 · 합계` 는 **관측된 것 기준**입니다.
  - 원화는 `data/global.json`의 원/달러(없으면 글로벌 시황의 실시간 환율)로 환산하고, 환율이 없으면 달러만 보여 줍니다. 줄을 누르면 tronscan.org의 그 거래가 새 탭으로 열립니다.
- **이번 주 경제 일정** — `data/calendar.json`. 미국 지표 중 중요도 ★★(Medium)·★★★(High)만, 한국 시간(KST)·한국어로 보여 줍니다.
  - 오늘은 노란 띠로 강조하고, 다가오는 일정은 `3시간 15분 뒤`처럼 10초마다 다시 세며, 지난 일정은 흐리게 `완료`로 바꿉니다. 예상·이전 값이 있으면 함께 적습니다.
  - 일정표가 이번 주 것이 아니면(자동 갱신이 멈췄으면) 화면에 그 사실을 밝힙니다.
- 휴대폰(≤900px)에서는 실시간 고래가 먼저, 일정이 아래로 쌓입니다. 탭을 벗어나면 TronGrid·TronScan 호출과 타이머를 모두 멈춥니다.

## 참고

- 고래 입출금·경제 일정은 공개 API의 관측값입니다. 모든 이체를 빠짐없이 보여 주는 목록이 아니며, 투자 조언이 아닙니다.

- 실시간 시세는 바이비트 공개 웹소켓(`wss://stream.bybit.com/v5/public/linear`)에서 받습니다.
- 스크리너는 `wss://stream.bybit.com/v5/public/linear`·`/spot`의 `tickers.{종목}`을 구독해 가격·24h 등락률·거래대금을 즉시 갱신하고, 전체 목록은 45초마다 REST로 보충합니다. 스크리너 탭을 벗어나면 소켓을 닫습니다.
- `.env.example`은 형식만 있는 빈 예시이며 실제 키는 포함되어 있지 않습니다.
- 글로벌 시황 값은 각 거래소·지수 제공처의 지연 시세입니다. 투자 조언이 아닙니다.
